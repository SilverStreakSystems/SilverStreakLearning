# Open questions

Recorded rather than resolved. An unanswered question is preferable to an invented answer.

1. **Stream granularity.** Eighteen streams is a judgment. Is "requirement → decision" genuinely
   separable from "research → requirement" in practice, or does the seam create a handoff that
   only exists because we drew it?
2. **Independence under one operator.** Compensating controls are declared, but no compensating
   control has been tested. Which of them actually catches anything?
3. **Refusal load.** If refusal is easy and frequent, does the workflow stall in a way that
   pushes people to route around it? We have no evidence either way.
4. **Burden offsets.** Each stream asserts an offset. None has been checked against a real
   educator's week.
5. **Evidence strength.** The model requires version-bound evidence but does not yet grade
   evidence strength per claim type. What strength is sufficient for which claim?
6. **Freshness thresholds.** How stale is stale? No threshold has been justified.
7. **Learning loop capacity.** Every stream routes findings somewhere. Nothing yet limits how
   many findings a destination can absorb before the loop is nominal.
8. **Small-district fit.** The architecture asserts it works for small and low-incidence
   programmes. That assertion is unverified and must not be stated publicly until it is.
