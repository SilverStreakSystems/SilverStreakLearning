# Traceability Model

Two parallel chains, both rendered on the Traceability view.

## Governance Spine

Belief → Principle → Standard → Requirement → Decision → Capability →
Implementation → Test → Evidence → Claim.

Answers: by what authority does this exist, and what allows it to be said aloud?

## Enterprise Outcome Chain

Human need → Outcome → Capability → Workflow → Data → Interface → Evidence of
effect.

Answers: whose life is better, and how would we know?

## Rules

- A claim is only permitted when an evidence record supports it; otherwise the
  claim is recorded as Refused with the reason.
- A broken link is a Finding, not a silent gap.
- Uncertainty is a first-class state: Unknown, Not Run, Partial, Blocked,
  Contested, Not Applicable, and Refused are all displayable.
