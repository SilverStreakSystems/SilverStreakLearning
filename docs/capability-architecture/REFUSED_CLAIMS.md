# Refused Claims — Capability Architecture v0.1

The following statements are deliberately withheld. Each is refused because no
evidence supports it, not because it is unimportant.

- **"SSLS has N capabilities."** Refused. SSLS has N candidate *records*. A
  record is a description of an ability, not the ability.
- **"The capability architecture is X% complete."** Refused. No percentage,
  score, or blended readiness index is computed anywhere in the system.
- **"Capability maturity is improving."** Refused. There is no baseline, no
  measurement method, and no independent observer.
- **"These capabilities are owned by these functions."** Refused. Every owner,
  role, and function in v0.1 is a candidate.
- **"This architecture is approved."** Refused. It is Research / Governed
  Candidate authority and no decision record promotes it.
- **"We are ready for a district pilot."** Refused. The pilot gate is uncrossed.
- **"We meet accessibility, privacy, or security requirements."** Refused. The
  capabilities that would produce that evidence are recorded as absent.
- **"AI features are governed."** Refused. There are no AI features and the AI
  gate is uncrossed.
- **"The taxonomy is complete."** Refused. The normalization pass records its
  own gaps, and several findings are Partial or Conflicted.

Refusal is a first-class verification state in this system. A refused claim is
recorded, visible, and reversible only by evidence.
