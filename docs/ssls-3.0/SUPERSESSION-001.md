## What this record is not

Replacing a transcription is a transcription act, not an approval act.

- No document moved from CANDIDATE to CANONICAL.
- No owner decision was recorded, closed, or implied.
- Per File 02 §9, supersession of a *governing* artifact occurs only by explicit owner decision. These documents govern nothing today, so nothing governing was superseded.
- No scope opened, no requirement was created, and no claim was authorized.
